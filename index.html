Put it on your site

    
Two ways into the GoDaddy site you already have. No new website, no monthly service, no login.

    

      

        
Paste it inEasiest

        
    
          
  1. Click Copy widget code below.
    2. 
          
  2. In GoDaddy: Edit Website → Add Section → HTML.
    3. 
          
  3. Paste into Custom Code, click Done, then Publish.
    4. 
        

        
<div id="hpq-block">
  <style>…the widget's look…</style>
  <form>…service, name, phone, address, day…</form>
  <script>…builds the text…</script>
</div>

        
      

      

        
Or link it in a frame

        
    
          
  1. Host this one file anywhere (it's a single page).
    2. 
          
  2. Add the same HTML section in GoDaddy.
    3. 
          
  3. Paste this, with your file's address in place of the example:
    4. 
        

        
<iframe id="hpq-frame" src="https://example.com/quote.html?embed"
  title="Get a fast quote"
  style="width:100%;max-width:560px;height:1150px;border:0"
  loading="lazy"></iframe>
<script>addEventListener('message',function(e){if(e.data&&e.data.hpqHeight)document.getElementById('hpq-frame').style.height=e.data.hpqHeight+'px'})</script>
